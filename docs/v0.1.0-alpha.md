# AppForge v0.1.0-Alpha - Release Notes

**Released**: May 20, 2026  
**Version**: 0.1.0-alpha  
**Status**: Production-grade Alpha

## Overview

AppForge is an Appwrite-native developer cockpit inside VS Code. This alpha release demonstrates the foundational architecture and delivers core project management workflows.

## Core Architecture

### Technology Stack

- **Language**: TypeScript (strict mode, no `any` types)
- **Framework**: VS Code Extension API
- **Build Tool**: esbuild
- **SDK**: Appwrite Node SDK
- **Validation**: Zod

### Directory Structure

```
src/
├── commands/          # Command handlers
│   ├── projectCommands.ts
│   ├── databaseCommands.ts
│   └── functionCommands.ts
├── providers/         # Tree data provider for sidebar
│   └── treeDataProvider.ts
├── services/          # Business logic
│   ├── appwriteClientService.ts
│   └── projectStorageService.ts
├── types/            # Type definitions
│   └── index.ts
├── utils/            # Utility functions
│   └── validators.ts
├── views/            # UI components (Phase 2+)
├── snippets/         # Code snippets (Phase 2+)
└── extension.ts      # Main entry point
```

## Phase 1: Project Scaffolding & Tree View (✓ Complete)

### Features Delivered

#### 1. **Sidebar Tree View**

- AppForge activity bar with dedicated sidebar
- Tree structure showing:
  - Projects (configurable, with switch capability)
  - Databases section (expandable, shows collections)
  - Functions section (expandable, shows function status)
  - Logs section (quick access)
- Refresh capability at any level
- Visual indicators for enabled/disabled functions

#### 2. **Project Management**

- **Add Project**: Guided setup with validation
  - Project name (1-100 characters)
  - Endpoint URL (valid HTTPS URL required)
  - Project ID (unique identifier)
  - API Key (securely stored in VS Code secret storage)

- **Remove Project**: Confirms deletion and removes all stored credentials
- **Switch Project**: Instantly switches active project context
- **List Projects**: Auto-populated in sidebar

#### 3. **Secure Credential Storage**

- API keys stored in VS Code's secure SecretStorage (encrypted)
- Project metadata stored in workspace state
- No credentials in plaintext
- Auto-loads active project on extension activation

#### 4. **Appwrite Client Service**

- **Singleton Pattern**: Single client instance across extension lifetime
- **Lazy Initialization**: Services initialized on first use
- **Clients Available**:
  - Databases
  - Functions
  - Account
  - Storage
  - Teams
- **Method Coverage**: All basic operations supported

#### 5. **Data Validation (Zod)**

- ProjectConfig validation (name, endpoint, projectId)
- ApiKey validation
- DatabaseName validation
- Type-safe schema inference

## User Experience

### Project Setup Workflow

1. Click "AppForge" in activity bar
2. Click "+ Add Project" or use Command Palette
3. Enter project details (guided input boxes with validation)
4. API key securely stored
5. Project appears in sidebar
6. Click project to switch context

### Tree View Interactions

- **Left-click project**: Switch to that project
- **Right-click project**: Context menu with "Remove" option
- **Expand sections**: View nested databases, collections, functions
- **Refresh button**: Reload all data from Appwrite

### Notifications

- ✓ Success messages on project add/remove/switch
- ⚠️ Warnings on destructive actions
- ✗ Error messages with context
- 🔄 Progress indicators for async operations

## Troubleshooting

### Extension won't activate

- Check workspace has VS Code >= 1.120.0
- Restart VS Code
- Check extension logs

### Projects not appearing

- Verify workspace state is writable
- Check if projects were previously added
- Restart extension

### Credentials not saving

- Verify VS Code secret storage is available
- Check OS-level keychain/credential manager
- Try re-adding project

## Architecture Decisions

### Why Singleton Pattern for Appwrite Client?

- Single source of truth for active project
- Prevents credential duplicates
- Simplifies context switching
- Clear lifecycle management

### Why Zod for Validation?

- Type-safe schema validation
- Clear error messages for users
- Minimal bundle size
- Zero runtime dependencies

### Why VS Code Secret Storage?

- OS-level encryption (keychain/credential manager)
- Secure by default
- VS Code handles key management
- User-controlled access
