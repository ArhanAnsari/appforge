# AppForge v0.1.1-Alpha - Release Notes

**Released**: May 23, 2026  
**Version**: 0.1.1-alpha  
**Status**: Production-grade alpha

## Overview

AppForge v0.1.1-alpha focuses on reliability, diagnostics, and safer project isolation for multi-project Appwrite workflows inside VS Code.

## What Changed

### Project-Scoped Architecture

- Appwrite services are created per project instead of through shared mutable client state
- Database and function workflows now resolve project context explicitly
- Cross-project contamination risk is removed from async operations

### Diagnostics

- Added raw REST verification beside SDK calls
- Added stored project metadata logging for database fetches
- Added a dedicated project environment verification command

### TreeView Stability

- Improved TreeItem identity handling
- Reduced refresh drift during rapid project switching
- Kept expansion behavior consistent across refresh cycles

### Documentation

- Refreshed README release notes
- Updated folder structure guide for the current architecture
- Added release notes for v0.1.1-alpha

## Implementation Notes

- TypeScript strict mode remains in place
- Zod validation continues to guard user input
- Output logging remains centralized
- Project storage still uses workspace state and SecretStorage

## Supported Workflows

- Add, remove, and switch Appwrite projects
- Inspect databases and collections in the sidebar
- Execute and deploy functions through commands
- Verify project identity and backend connectivity
- Troubleshoot empty database results with diagnostics

## Notes

This release is a hardening update rather than a feature expansion. It is intended to make AppForge safer for real multi-project Appwrite development.
